# Tracking And Application Handoff

## Notion Update

Only update Notion when the user explicitly asks. Apply the smallest confirmed stage, priority, source, or metadata change and report it.

## Begin Applying

When the user chooses a card and asks to apply, invoke `job-application` and carry forward the Notion page ID and URL, company, role, canonical posting, stage, priority, deadlines, notes, fit reasons, risks, missing details, and likely materials.

The application workflow owns branch setup, job files, strategy, materials, builds, and later status updates.
