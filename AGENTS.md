# Resume Tracker

This repository manages job leads, tailored application materials, and application tracking.

## Route The Request

- Use `$create-job-leads` to research, compare, or lightly triage roles. Do not create branches, Notion cards, or tailored materials during lead triage.
- Use `$job-picker` to rank or inspect existing Notion application cards.
- Use `$job-application` when the user chooses to apply, tailor materials, track an active application, or prepare submission instructions.

## Shared Rules

- Notion `Job Applications` is the tracking source of truth.
- Prefer the canonical employer posting over aggregator links.
- Never invent candidate facts, metrics, tools, credentials, or ownership.
- Treat `resume/master_resume.md` as the truthful source inventory.
- Keep reusable master-resume changes separate from job-specific commits.
- Discord is a final-state activity feed, not a source of truth. Do not post for read-only, blocked, or incomplete runs.

Application mechanics, phase routing, files, builds, cover-letter voice, and wrap-up rules live in the selected skill. Do not duplicate them here.
