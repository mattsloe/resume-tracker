# Software Engineer 1 (Full-Stack) — Prometheum

## Company
Prometheum

Prometheum develops blockchain infrastructure for securities, operating as an
SEC-registered broker-dealer network. The company was the first SEC-registered
special purpose broker-dealer and the first to trade ETH within a traditional
brokerage account.

## Snapshot
- Location: Remote (United States or Canada)
- Employment type: Full time, W2
- Level: Entry level (early career)
- Salary: $90,000–$120,000 plus stock options

## Role Overview
Early-career position for engineers seeking rapid growth on production
systems with regulatory significance. Work spans the TypeScript/Node back end
and React front end, starting with small, clearly defined pieces and
expanding as system knowledge develops.

## Key Responsibilities
- Deliver work spanning the full stack, from fixes to features to technical debt
- Employ AI coding tools as standard practice, applying rigorous review standards
- Map end-to-end request flows across front end, API, services, and databases
- Participate in code reviews and all scrum ceremonies
- Collaborate directly with Product, QA, and UX teams
- Debug and resolve QA/UAT issues through pairing when needed

## Required Qualifications
- Up to 2 years professional software engineering experience
- Working knowledge of JavaScript or TypeScript with Node.js or React familiarity
- Hands-on experience with AI coding assistants, plus the judgment to know when their output is wrong
- Relational database and SQL knowledge
- Git workflow competency
- Clear written communication, with a strong command of the English language
- U.S. or Canadian work authorization
- Ability to pass a comprehensive background check

## Preferred Qualifications
- Microservices, Docker, or AWS exposure
- Automated testing experience
- Finance, brokerage, trading, or blockchain background
- Jira or Confluence experience
