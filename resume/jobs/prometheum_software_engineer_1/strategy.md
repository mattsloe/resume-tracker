# Application Strategy — Prometheum, Software Engineer 1 (Full-Stack)

## Positioning / angle

Matt has no professional software engineering title, but the posting explicitly
targets "up to 2 years" experience and an entry-level ramp path ("start with
small, clearly defined pieces... expanding as system knowledge develops").
The honest, strongest angle is: **a self-directed full-stack builder with one
real, working AI-assisted project that happens to overlap almost exactly with
the required stack, backed by directly relevant CS coursework, applying for
the on-ramp the posting itself describes** — not someone pretending to have
industry experience he doesn't have.

Do not try to make the non-technical work history (community research,
bartending) sound technical. Use it only for the soft-skill requirements the
posting actually lists (clear written communication, fast-paced/detail-driven
work, staying accountable). Everything else rides on the project and the
degree.

## ATS keyword strategy

Use the posting's own vocabulary, verbatim where it's truthful, spread
naturally across Summary, Projects, and Skills (not just crammed into one
line): full-stack, front end, back end, API, TypeScript, React, JavaScript,
SQL, relational database, Git / version control, AI coding assistants,
code review / reviewing AI-generated code, debugging, data structures,
systems programming.

## Content decisions

- Keep the Projects section expanded (3 bullets), not compressed to one —
  it's the highest keyword-density, most relevant section on the resume.
- Add "Git / version control" and "relational databases" explicitly to
  Skills, not just implied by "SQL."
- Rephrase project bullets to mirror JD language directly, e.g. "mapped
  requests across the front end and back end" instead of vaguer phrasing.
- Trim Experience bullets to the minimum needed for the "clear
  communication" / "fast-paced" soft-skill keywords — that section carries
  little ATS weight for a technical role.
- Dropped the Education coursework bullet in the final draft: once Skills
  explicitly lists systems programming, data structures, digital circuits,
  and relational databases, the coursework line was pure duplication and
  the only thing keeping the resume off one page.
- Cover letter stays narrative (lower ATS weight there), but should still
  hit Git and "relational database" by name at least once each.
